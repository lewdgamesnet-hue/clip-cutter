PREMIUM CLIP CUTTER - WINDOWS INSTALLER

1) Copy this entire folder to a Windows 10/11 PC.
2) Double-click BUILD_WINDOWS.bat.
3) The builder downloads FFmpeg, installs the required Python packages, builds the standalone EXE, and creates:
   Output\PremiumClipCutter_Setup.exe
4) Run PremiumClipCutter_Setup.exe.
5) The installer creates a Desktop shortcut and Start Menu shortcut.

After installation, Python and FFmpeg are NOT required on the target PC.

IMPORTANT:
- The build PC needs internet access.
- The first run of the app downloads the selected Whisper model. This can be large.
- The final EXE is large because Whisper/Torch are packaged inside it.
- Use the app with content you have permission to download/use.
